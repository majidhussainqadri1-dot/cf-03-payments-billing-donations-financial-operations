# CF-03 Definition of Done Ledger

## Completed in source

- Canonical financial ownership boundaries and 0% Clinic/Marketplace commission.
- Product/price/disclosure, checkout command, idempotency and provider-evidence contracts.
- Immutable balanced ledger, invoice, subscription, refund, reconciliation, close, export, incident and backup domain laws.
- Additive schema, migration runner design, outbox/audit tables and non-destructive uninstall boundary.
- File 00 facts only; File 24 assurance only; provider-neutral integration.
- Automated PHP 8.1–8.3 syntax/domain/adversarial/package checks.

## External acceptance gates not representable by repository code alone

- Founder-approved legal entity, bank/provider accounts and authorized signatories.
- Qualified Pakistan/target-market legal, consumer, tax, accounting and invoice review.
- Selected provider contract, data region, PCI responsibility matrix and sandbox acceptance.
- Hostinger fresh install/upgrade, browser, RTL, accessibility, performance and real-role acceptance.
- Independent penetration test, key rotation, backup/restore, provider-exit and rollback rehearsal.
- Finance staffing, separation-of-duties assignment, daily reconciliation, incident response and operational monitoring.

The source candidate must remain fail-closed until every external gate has dated evidence.
